# FitBuddy AI 💪

FitBuddy AI is a beginner-friendly fitness and activity web application built with Python and FastAPI.

## About

FitBuddy AI helps users choose simple and enjoyable activities based on their fitness or activity goal.

The application provides general activity suggestions and encourages users to start gently, take breaks, and stay active.

## Features

- User details form
- Name, age, and gender input
- Fitness / activity goal selection
- Goal-based activity plans
- Input validation
- Safety note
- Simple and clean web interface
- Create another plan option

## Activity Goals

The application supports these goals:

- Improve my fitness
- Build strength
- Improve running
- Become more active

## Technologies Used

- Python
- FastAPI
- Jinja2
- HTML
- CSS
